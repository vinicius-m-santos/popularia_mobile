## Como pedir ajuda

1. Abra o app e vá em **Conta → Suporte e contato** para enviar uma mensagem com seu @ e a descrição do problema.
2. Se o app não abrir, escreva para o e-mail acima com: modelo do iPhone, versão do iOS, versão do app, o que você fez e o horário aproximado.
3. Para denúncias de conteúdo, use **⋯ → Denunciar** na publicação, comentário, perfil ou comuna. Para bloquear alguém, use **⋯ → Bloquear**.
4. Para excluir a conta, abra **Conta → Excluir conta**. A exclusão é definitiva para os dados pessoais; respostas mantêm marcadores sem texto.

## O que o suporte não faz

- Não pedimos senha, código de recuperação, token ou código de verificação.
- Não alteramos sua senha por e-mail sem confirmação de identidade.
- Não removemos conteúdo por mensagem de terceiros; use o fluxo de denúncia.

## Privacidade

Não envie documentos pessoais ou dados sensíveis por e-mail. Para exercer direitos de privacidade, use o contato indicado na Política.
